# Django-приложение для работы с музыкальными альбомами

## Описание проекта

Веб-приложение разработано на Django и предназначено для сохранения и загрузки информации о музыкальных альбомах в форматах JSON и XML.

## Функциональные возможности

- Добавление информации об альбоме через HTML-форму.
- Проверка введённых данных перед сохранением.
- Сохранение информации в форматах JSON и XML.
- Загрузка файлов JSON и XML на сервер.
- Проверка загруженных файлов на корректность.
- Удаление файлов, которые не прошли проверку.
- Просмотр списка сохранённых файлов с корректными данными.
- Вывод сообщения, если подходящие файлы отсутствуют.

## Используемые технологии

- Python
- Django
- HTML
- CSS
- JSON
- XML
- Git и GitHub

## Установка и запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/django-albums.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd django-albums
   ```

3. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

4. Активируйте виртуальное окружение в Windows:

   ```powershell
   .venv\Scripts\Activate
   ```

5. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

6. Выполните миграции:

   ```bash
   python manage.py migrate
   ```

7. Запустите сервер:

   ```bash
   python manage.py runserver
   ```

8. Откройте в браузере адрес:

   http://127.0.0.1:8000/

## Структура проекта

- `myproject/` — настройки и основные URL-адреса проекта Django.
- `myapp/` — приложение для работы с музыкальными альбомами.
- `myapp/templates/` — HTML-шаблоны страниц.
- `myapp/data/` — папка для хранения файлов с данными.
- `manage.py` — файл для управления проектом.
- `requirements.txt` — список необходимых библиотек.

## Назначение проекта

Проект создан в учебных целях для изучения Django, обработки HTML-форм, работы с файлами JSON и XML, проверки данных и использования системы контроля версий Git.
